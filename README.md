## 🌟 The Problem & The SkillBridge Solution

Applying to hundreds of entry-level job postings with zero feedback is exhausting and demoralizing for freshers. Most job boards demand 2–3 years of experience for "junior" roles, while applicant tracking systems discard resumes without explanation.

**SkillBridge eliminates rejection silence with actionable guidance:**
1. **Instant AI Diagnostic**: Upload your resume or paste your background to see verified skills, readiness score (0–100), and targeted skill gaps for your chosen career path.
2. **Curated Zero-Cost Micro-Roadmaps**: Free, bite-sized tutorials from freeCodeCamp, Harvard CS50, Coursera (Free Audit), Traversy Media, and MDN Web Docs.
3. **Industry Masterclasses (Courses Pro)**: Hands-on, production-grade courses with verifiable certificates and senior dev code reviews.
4. **1:1 Industry Mentorship**: Live coding mocks, resume roasts, and system design sessions with leads from Google, Stripe, Airbnb, and Amazon.
5. **Opportunity Matcher & 1-Click Quick Apply**: Match % calculated in real-time against your detected skills with pre-filled, tailored cover letters.

## 🚀 Core Features

### 1. 🔍 AI Skill Gap Diagnostic (`/analyze`)
- **Multi-Modal Input**: Drag-and-drop resume upload (PDF, DOCX, TXT) or paste coursework / LinkedIn "About" text.
- **1-Click Starter Personas**: Instant test-drives for *CS Graduate (Alex)*, *Self-Taught Dev (Maya)*, and *Data Aspirant (Jordan)*.
- **Dynamic Role Calibration**: Benchmarked against 6 high-growth entry-level pathways (*Frontend*, *Full-Stack*, *Data Analyst*, *UI/UX Designer*, *Python Backend*, *AI & Prompt Specialist*).
- **Radial ScoreGauge (0–100)**: Visual readiness tier (*Foundational*, *Emerging Talent*, *Job Ready*).
- **Recruiter Perspective**: Clear breakdown of verified core proficiencies vs critical gaps with point impact (e.g. `+15 pts`).

### 2. 📚 Personalized Micro-Learning Paths (`/learn`)
- Curated 100% free courses and micro-modules from world-class educators.
- Filter by skill tag or status (*To Do*, *Started / In-Progress*, *Done / Completed*).
- **Dynamic Score Boost**: Completing a module awards readiness points and triggers celebratory confetti.

### 3. 🎓 Industry-Grade Masterclasses (`/courses`)
- Comprehensive, project-driven masterclasses:
  - *Full-Stack Web Engineering 2025* (Next.js 15, Prisma, PostgreSQL, Docker)
  - *Generative AI & LLM Application Development* (LangChain, Vector DBs, RAG, FastAPI)
  - *Product UI/UX & Design Systems Masterclass* (Figma Variables, Design Tokens, Auto-Layout)
  - *Data Analytics Bootcamp* (Advanced SQL, Python Pandas, PowerBI Dashboards)
  - *React 19 & Next.js Architecture* (Senior Patterns for Juniors)
  - *The Fresher Technical Interview Playbook* (DSA Patterns, System Design, Offer Negotiation)
- **Interactive Syllabus Modal**: Deep dive into individual module lessons and capstone project deliverables.
- **Courses Pro Subscription**: Unlimited access ($12/mo billed annually or $19/mo) with certificates of completion.

### 4. 👥 1:1 Industry Tech Mentorship (`/experts`)
- Connect directly with verified leads from **Google**, **Stripe**, **Airbnb**, **Amazon**, **Uber**, and **Microsoft**.
- **Specialized Session Formats**:
  - *1:1 Portfolio & Resume Roast* (30 mins)
  - *Algorithmic Live Coding Mock* (45 mins)
  - *Product Design Whiteboard Challenge* (45 mins)
  - *Junior System Design & Offer Negotiation* (45 mins)
- **Interactive Booking Flow**: Calendar day/time picker, goal notes, and automated Google Meet room link generation.
- **Mentorship Subscription Passes**: *Single Session Pass* ($39), *Mentorship Starter* ($49/mo), and *Career Accelerator Elite* ($119/mo).

### 5. 💼 Opportunity Matcher (`/opportunities`)
- Verified internships, freelance starter gigs, and entry-level positions with compensations and stipends.
- **Dynamic Skill Matchup**: Shows matched skills ($\checkmark$) vs missing skills ($!$) with direct links to bridge them.
- **Multi-Filter Engine**: Filter by Job Type, Workplace (Remote, Hybrid, On-site), and Minimum Match ($50\%+$, $75\%+$, $85\%+$).
- **1-Click Quick Apply Modal**: Pre-fills student details and auto-generates a personalized cover letter highlighting matching skills.

### 6. 📊 Student Dashboard (`/dashboard`)
- High-level metric cards: Readiness Score, Skills Mastered, Roadmap Progress %, and Available Matched Gigs.
- **Highest Impact Next Step**: Recommends the specific micro-skill to bridge today.
- **Enrolled Masterclasses**: Quick resume links for active Courses Pro projects.
- **Upcoming 1:1 Mentorship**: Session schedule with direct Google Meet links.

### 7. 💳 Unified Pricing Hub (`/pricing`)
- Side-by-side comparison of **Courses Pro** and **Expert Mentorship** tracks.
- Monthly vs Annual billing toggle with 35% savings.
- Verified student discount voucher (`FRESHER30` for 30% off).

### 8. 👤 Student Profile & Settings (`/profile`)
- Editable student background, target role, education, and links.
- Manual skill inventory manager (add/remove skills on the fly).
- 1-Click preset loaders and safe LocalStorage data reset.

## 🏁 Getting Started

### Prerequisites
- **Node.js**: v18.18.0 or higher (v20+ recommended)
- **npm**: v9+ or equivalent package manager

### 1. Clone & Install Dependencies
```bash
# Navigate to the project root
cd "Skill Bridge"

# Install dependencies
npm install
```

### 2. Start the Development Server
```bash
npm run dev
```

Open **[http://localhost:3000](http://localhost:3000)** in your browser to experience SkillBridge.

### 3. Production Build
```bash
# Run TypeScript validation and static page generation
npm run build

# Start production server
npm start
```

## 💡 Key User Flows to Try

1. **Test-Drive the AI Analyzer**:
   - Go to `/analyze`.
   - Click one of the quick persona buttons (e.g. `🎓 CS Graduate (Alex)`).
   - Click **Run AI Skill Analysis** to watch the simulated keyword extraction and view the detailed diagnostic report.
2. **Bridge Gaps & Boost Score**:
   - Go to `/learn`.
   - Click **Done** on any in-progress micro-course to see your readiness score increase by `+4 pts` with confetti.
3. **Explore Masterclasses & Enroll in Courses Pro**:
   - Go to `/courses`.
   - Click **View Syllabus** to view detailed module lessons.
   - Click **Upgrade to Courses Pro** to simulate instant subscription activation.
4. **Book a 1:1 Session with a Tech Lead**:
   - Go to `/experts`.
   - Click **Book 1:1 Session** on Sarah Jenkins or Arun Kumar.
   - Choose your session format, pick a time slot, and submit to generate your meeting room.
5. **Quick Apply to a Matched Job**:
   - Go to `/opportunities`.
   - Filter by **Remote** and **Paid Internship**.
   - Click **Quick Apply** to review the auto-generated cover letter highlighting your matched skills.
